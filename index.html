初期設定（端末ごとに1回）

Firebaseコンソールでコピーした firebaseConfig を貼り付けてください。設定はこの端末の中にだけ保存され、ソースコードやGitHubには含まれません。手順は README を見てください。

ログイン

全端末で同じGoogleアカウントでログインすると、そのアカウントが同期グループになります。ルームコードは要りません。

正直な制約
Webアプリの仕様上、確実に鳴らせるのはアプリを開いている間だけです。閉じている／スリープ中の端末ではOSに止められる場合があり、特にiPhoneはアプリを開いた状態が前提です。
推奨：寝る前に全端末でこのアプリを開き、充電しながら「画面ON維持」をON、音量を上げておくこと。大事な朝は端末標準アラームの併用を推奨します。
